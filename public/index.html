About

I’m a second-year Software Engineering student at Mbarara University of Science and Technology (MUST) in Uganda. I got into computing because I saw how software can quietly change everyday life — how a farmer checks prices, how a small hotel takes bookings, how citizens hold institutions accountable.

Right now I’m focused on the fundamentals that make good engineers: writing clean object-oriented code, understanding how data is stored and queried, and grasping what happens underneath the hood when software runs.

  • Java — Object-Oriented Programming

    Classes, inheritance, encapsulation and designing software that scales with structure.

  • SQL & Databases

    Designing schemas, writing queries, and the data models behind real applications.

  • Operating Systems

    Processes, scheduling, memory and how the system juggles it all at once.

  • Computer Architecture

    From logic gates to instruction sets, the hardware layer software rides on.
